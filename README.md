# Forensic Evidence Management System (ForensicRecon)

Welcome to the ForensicRecon platform! Below is an A to Z list of all the features and capabilities integrated into the website.

## Features List (A to Z)

* **Animated Counters & Statistics**: Real-time stats visualization and animated data counting.
* **Case Calendar Management**: Organize and track important case events and deadlines.
* **Crime Mapping (Geospatial Analysis)**: Visualizing crime data and geospatial locations on interactive maps.
* **Crime Scene 3D Visualization**: Interactive 3D reconstruction and visualization of crime scenes using Three.js and React Three Fiber.
* **Crime Timeline**: Chronological tracking and visualization of case events.
* **Dark/Light Theme Support**: Easily toggleable dark and light modes for optimal user experience.
* **Dashboard Interface**: Centralized hub for investigators to view recent cases, metrics, and quick actions.
* **Data Visualization & Charts**: Interactive graphs and charts for analytics using Chart.js.
* **Error Boundaries & Crash Handling**: Robust error handling to prevent the entire app from crashing during unexpected errors.
* **Evidence Comparison**: Specialized tools to compare multiple pieces of evidence side-by-side.
* **Evidence Management**: Detailed tracking, organization, and storage of forensic evidence.
* **Evidence Upload**: Secure file and image uploading system for adding new evidence to cases.
* **FontAwesome Iconography**: Comprehensive and intuitive visual cues across the platform.
* **Image Lightbox & Viewer**: Detailed examination of image evidence with full-screen lightbox, zoom, and pan capabilities.
* **Lazy Image Loading**: Performance optimized image rendering for faster page loads.
* **Notifications & Alert System**: Real-time, non-intrusive toast notifications for system events and updates.
* **Onboarding Interactive Tour**: Guided, step-by-step interactive tour for new investigators and users.
* **Page Transitions & Loading States**: Smooth and fluid animations between routes using Framer Motion.
* **Real-time Collaboration**: Multi-user, live collaboration on ongoing cases using Supabase Realtime.
* **Search Functionality**: Global search bar for quick access to specific cases, evidence, and records.
* **Security & Audit Logging**: Tracking user actions, access control, and monitoring platform security.
* **Session Timeout & Auto-logout**: Automatic security measures that log users out after periods of inactivity.
* **Skeleton Loading States**: Enhanced UI experience with placeholder skeletons during data fetching.
* **Supabase Backend Integration**: Robust backend powered by Supabase for authentication, database management, and real-time sync.
* **Tabbed Interface Navigation**: Efficient UI organization using modular tabs for cleaner evidence and case viewing.
* **User Authentication**: Secure login and access control system for authorized personnel.

---

## Tech Stack Highlights
- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **3D Engine**: Three.js, React Three Fiber, React Three Drei
- **Animations**: Framer Motion
- **Backend & Auth**: Supabase
- **Data Viz**: Chart.js, React ChartJS 2
